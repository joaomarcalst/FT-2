# 📚 Fenômenos de Transporte 2

Anotações e resolução de exercícios da disciplina Fenômenos de Transporte 2 (UFG).

🔗 **Site publicado:** [joaomarcalst.github.io/FT-2](https://joaomarcalst.github.io/FT-2/)

## Estrutura

* `docs/` — conteúdo-fonte do site (MkDocs + Material)
  * `Aulas/` — anotações de cada aula
  * `Exercicios/` — resolução de listas
  * `img/` — imagens usadas nas páginas
* `mkdocs.yml` — configuração do site

## Rodando localmente

```bash
pip install mkdocs-material
mkdocs serve
```

## Publicando

```bash
mkdocs gh-deploy
```
